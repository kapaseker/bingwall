# Package version 1 as an amd64 Debian package

Version 1 will be distributed as an amd64 `.deb`, targeting Ubuntu 24.04 LTS or newer with GNOME and Linux Mint 22 or newer with Cinnamon. The package carries the Bingwall executable and systemd user-unit templates; the application activates the user's timer only after Daily Change is explicitly enabled. ARM64, older distributions, and portable package formats are deferred so the initial release can validate one installation and update path.
