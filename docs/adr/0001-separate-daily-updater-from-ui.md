# Separate daily wallpaper updates from the UI

Bingwall will use a persistent per-user systemd timer to run its Wallpaper Update at 08:00 local time each day, independently of the Iced application window. Daily Change is off by default: the first launch may fetch previews but never applies a wallpaper or activates unattended changes until the user explicitly opts in through the UI. Enabling Daily Change activates the timer and immediately applies the Current Wallpaper; disabling it deactivates future runs without reverting the Applied Wallpaper. If an enabled computer misses 08:00, systemd runs the missed update after the next startup or wake. Requiring the GUI to remain open would make daily updates unreliable; the UI instead remains responsible for browsing, previewing, and configuration. The updater does not poll for feed changes throughout the day.
